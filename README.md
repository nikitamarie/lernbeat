# LernBeat 🎧

Kostenlose Lern-App (PWA) für die 5. Klasse Gymnasium Niedersachsen.
Fotos von Arbeitsblättern hochladen und daraus Zusammenfassung, Merksätze, Karteikarten, Spickzettel, Vokabeltrainer und Probearbeiten mit Auswertung bekommen.

- Läuft komplett im Browser (iPad: Safari → Teilen → „Zum Home-Bildschirm“)
- Daten bleiben lokal auf dem Gerät (IndexedDB), Sicherung als Datei möglich
- KI: Google Gemini API (Free Tier), der Schlüssel wird nur auf dem Gerät gespeichert
- Hosting: GitHub Pages (Settings → Pages → Branch `main`, Ordner `/root`)
